Cactus CSS

Cactus is a small, classless CSS stylesheet for content-first HTML. It is designed to make rendered Markdown look clean, readable, and calm by default.

This document exists to demonstrate how common Markdown elements are styled.

Blockquote

Markdown blockquotes should be visually distinct but not overpowering.

They often span multiple lines and paragraphs.

Final notes

This stylesheet intentionally avoids layout, components, or utilities. It focuses on sensible defaults for content and documentation.

Use it as a starting point, not a framework.
